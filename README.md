# VastLLM

Окно Windows с кнопками **Up** / **Down**: арендует GPU на [QuickPod](https://console.quickpod.io), поднимает на нём
OpenAI-совместимый API (движок [Strata](https://github.com/Niko1221/Strata), модель Qwen3.8-Flash-Next abliterated IQ3_XXS) и даёт
его на этом ПК по адресу `http://127.0.0.1:8080/v1`. Название осталось от версий для Vast.ai.

## Установка

1. Скачать `VastLLM.exe` из [Releases](../../releases/latest) в любую папку. Больше ничего ставить не нужно.
2. В [кабинете QuickPod](https://console.quickpod.io/templates) один раз создать шаблон: образ `ghcr.io/kirilltsuran/vast-llm`,
   тег `3`, launch mode `docker`, docker options `-p 22:22`, диск 150 ГБ. Шаблоны создаются только из кабинета — API-ключ этого не умеет.
3. Запустить программу один раз — рядом появится `config.json`. Вписать `quickpod_api_key` (Settings → API keys) и
   `quickpod_template_uuid` (UUID шаблона из п. 2).
4. **Up** → 15–25 минут (машина скачивает ~78 ГБ модели) → «Работает». Клиент (ZCode и т.п.): OpenAI-compatible,
   URL `http://127.0.0.1:8080/v1`, модель `sc117-abliterated-iq3_xxs`, ключ любой, окно контекста 262144.
   Уровень рассуждений — полем `reasoning_effort` в запросе: `none`, `low`, `medium`, `high`.
   Запросы обрабатываются по одному на полной скорости, остальные ждут в очереди (`parallel` в `image/model.json`).
5. **Grafana** — `http://127.0.0.1:3000`: дашборды «LLM — метрики» (модель, GPU, CPU, RAM, диск, сеть, сервисы) и «LLM — логи».
   Данные хранятся до 3 дней и удаляются вместе с машиной.
6. **Down** — удаляются все машины программы, которые есть у QuickPod (и известные программе, и с её меткой, о которых она
   не знала), и только тогда пишется «оплата остановлена». Работающая машина удаляется **только** кнопкой Down (или «Да»
   в вопросе при закрытии окна); машина, которая не смогла поднять модель, удаляется сама, и Up берёт следующую. Если на
   балансе QuickPod кончатся деньги, он машину не удаляет, а останавливает — диск при этом оплачивается дальше: пополнить
   баланс, затем Down и Up.

## Какая машина арендуется

Свободная машина с одной выбранной видеокартой (RTX 3090 / 3090 Ti / 4090 / 5090), у которой не меньше 62 ГБ RAM, 16 потоков CPU,
150 ГБ диска, сеть от 300 Мбит/с и надёжность от 95 %. Первой берётся конфигурация, на которой Strata даёт ~110 ток/с на одной
RTX 3090: от 100 ГБ RAM, PCIe 4.0 x16 и от 20 потоков (например, Ryzen 9 5900X и 125 ГБ). Среди остальных — самая дешёвая, при равной
цене — с большим числом ядер. Процессоры без AVX2 (на них движок не работает) не берутся вовсе.

По умолчанию (`fast_only: true`) берётся **только** быстрая конфигурация. Если её нет, Up ждёт, проверяя QuickPod раз в
минуту, до `wait_fast_minutes` (30) — ничего не арендуя, — и потом пишет, что свободно. `fast_only: false` — брать и
медленные. Машина, которая не подошла (не скачала модель, движок падает), блокируется на 3 часа; без AVX2 или с малой
памятью — навсегда (`blocked` в `state.json`). Отказ QuickPod при аренде (машину только что заняли) её не блокирует.

Движок настроен по замерам на RTX 3090: один запрос за раз (слоты отнимают видеопамять и выключают черновики MTP), словарь
черновиков `cyrillic`, резерв видеопамяти 700 МиБ, по одному потоку пула на физическое ядро.

## Файлы рядом с exe

| Файл | Что это |
|---|---|
| `config.json` | ключ и шаблон QuickPod и настройки: `gpu`, `fast_only`, `wait_fast_minutes`, `cheapest_grace_seconds`, `race_two_hosts`, `local_port`, `grafana_port`, `usd_rub`, `autostart`, `log_retention_days`, `debug_log` |
| `state.json` | все арендованные машины (основная и ещё не выбранные при Up); пишется сразу после аренды, атомарно. После перезапуска программы или ПК она сверяется с QuickPod и подключается снова, машины не теряются |
| `ssh_key.pem` | SSH-ключ программы; публичная часть передаётся в контейнер при аренде |
| `logs\vast-llm-<дата>.log` | журнал по дням |

`state.json` без `"provider": "quickpod"` (от версий для Vast) не загружается: номера машин и чёрный список Vast к QuickPod
не относятся.

## Как устроено

Весь код репозитория — Go, без cgo.

- `cmd/vastllm`, `internal/app` — программа для Windows. QuickPod API: поиск (`/rentable`), аренда по шаблону
  (`/update/api/createpod`), список и удаление машин, баланс; по желанию — аренда двух машин сразу с выбором первой поднявшейся
  (`race_two_hosts`, лучшей даётся фора); SSH-туннель `127.0.0.1:8080 → машина:127.0.0.1:8080`, переподключение, цены в рублях по
  курсу ЦБ, сворачивание в трей, автозапуск.
- `cmd/llmd` — единственный процесс контейнера: свой sshd (вход только по ключу программы), скачивание весов по закреплённой
  ревизии с проверкой SHA256, подготовка весов для движка, запуск Strata с перезапуском при падении, экспортёр метрик,
  дашборды Grafana. API слушает только `127.0.0.1` внутри контейнера.
- `image/` — образ `ghcr.io/kirilltsuran/vast-llm:3`: Strata 0.1.42 (компилируется при сборке образа под RTX 30/40/50),
  Prometheus, node_exporter, Loki, Alloy, Grafana. Модель задана в `image/model.json`.

## Сборка

```sh
go test ./...
go build -trimpath -ldflags "-H windowsgui -s -w" -o dist/VastLLM.exe ./cmd/vastllm
```

CI: `test.yml` — проверки; `image.yml` — образ при изменениях в `image/` и `cmd/llmd/`; `release.yml` — `VastLLM.exe` по тегу `v*`.
Образ из другой ветки получает только тег своего коммита; чтобы его попробовать, укажите этот тег в шаблоне QuickPod.

Strata — сторонний движок (MIT), в образ попадает его исходный код и собранный бинарник.
