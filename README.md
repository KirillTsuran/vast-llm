# VastLLM

Окно Windows с кнопками **Up** / **Down**: арендует GPU на [Vast.ai](https://vast.ai), поднимает на нём OpenAI-совместимый API
(движок [Strata](https://github.com/Niko1221/Strata), модель Qwen3.8-Flash-Next abliterated IQ3_XXS) и даёт его на этом ПК
по адресу `http://127.0.0.1:8080/v1`.

## Установка

1. Скачать `VastLLM.exe` из [Releases](../../releases/latest) в любую папку. Больше ничего ставить не нужно.
2. Запустить один раз — рядом появится `config.json`. Вписать `vast_api_key` (console.vast.ai → Keys).
3. **Up** → 15–25 минут (машина скачивает ~78 ГБ модели) → «Работает». Клиент (ZCode и т.п.): OpenAI-compatible,
   URL `http://127.0.0.1:8080/v1`, модель `sc117-abliterated-iq3_xxs`, ключ любой, окно контекста 262144.
   Уровень рассуждений — полем `reasoning_effort` в запросе: `none`, `low`, `medium`, `high`.
4. **Grafana** — `http://127.0.0.1:3000`: дашборды «LLM — метрики» (модель, GPU, CPU, RAM, диск, сеть, сервисы) и «LLM — логи».
   Данные хранятся до 3 дней и удаляются вместе с машиной.
5. **Down** — машина удаляется, оплата прекращается. Машины удаляются **только** кнопкой Down
   (или «Да» в вопросе при закрытии окна).

## Какая машина арендуется

Самая дешёвая проверенная машина с выбранной видеокартой (RTX 3090 / 4090 / 5090), у которой есть 64 ГБ RAM, 16 потоков CPU,
150 ГБ диска, драйвер под CUDA 13, сеть от 500 Мбит/с и почти бесплатный трафик. Конфигурация измерена на RTX 3090 + Ryzen 7 5700X:
пик 21,9 ГиБ VRAM и 55,6 ГиБ RAM контейнера при одном запросе и окне 262144. Машину без AVX2 или с меньшим лимитом памяти
контейнер отклоняет сам, и следующий Up берёт другую.

## Файлы рядом с exe

| Файл | Что это |
|---|---|
| `config.json` | ключ Vast и настройки: `gpu`, `cheapest_grace_seconds`, `datacenter_only`, `race_two_hosts`, `local_port`, `grafana_port`, `usd_rub`, `autostart`, `log_retention_days`, `debug_log` |
| `state.json` | все арендованные машины (основная и ещё не выбранные при Up); пишется сразу после аренды, атомарно. После перезапуска программы или ПК она сверяется с Vast и подключается снова, машины не теряются |
| `ssh_key.pem` | SSH-ключ программы; публичная часть передаётся в контейнер при аренде |
| `logs\vast-llm-<дата>.log` | журнал по дням |

Файлы версии 1.x читаются как есть.

## Как устроено

Весь код репозитория — Go, без cgo.

- `cmd/vastllm`, `internal/app` — программа для Windows. Vast API: поиск, аренда двух машин параллельно с выбором первой
  поднявшейся (`race_two_hosts`, дешёвой даётся фора), SSH-туннель `127.0.0.1:8080 → машина:127.0.0.1:8080`, переподключение,
  цены в рублях по курсу ЦБ, сворачивание в трей, автозапуск.
- `cmd/llmd` — единственный процесс контейнера: свой sshd (вход только по ключу программы), скачивание весов по закреплённой
  ревизии с проверкой SHA256, подготовка весов для движка, запуск Strata с перезапуском при падении, экспортёр метрик,
  дашборды Grafana. API слушает только `127.0.0.1` внутри контейнера.
- `image/` — образ `ghcr.io/kirilltsuran/vast-llm:2`: Strata закреплённого коммита (компилируется при сборке образа под
  RTX 30/40/50), Prometheus, node_exporter, Loki, Alloy, Grafana. Модель задана в `image/model.json`.

## Сборка

```sh
go test ./...
go build -trimpath -ldflags "-H windowsgui -s -w" -o dist/VastLLM.exe ./cmd/vastllm
```

CI: `test.yml` — проверки; `image.yml` — образ при изменениях в `image/` и `cmd/llmd/`; `release.yml` — `VastLLM.exe` по тегу `v*`.
Образ из другой ветки получает только тег своего коммита; программа берёт его через переменную окружения `VASTLLM_IMAGE`.

Strata — сторонний движок (MIT), в образ попадает его исходный код и собранный бинарник.
