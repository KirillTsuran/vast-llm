# vast-llm

Одна кнопка: арендовать GPU на [Vast.ai](https://vast.ai), поднять на нём OpenAI-совместимый API (TabbyAPI + ExLlamaV3,
Qwen3.8-27B) и пользоваться им на своём ПК по адресу `http://127.0.0.1:8080/v1`. Кнопка Down удаляет машину — оплата и хранение прекращаются.

## Как пользоваться

1. Скачать `vast-llm.exe` из [Releases](../../releases/latest) и запустить. Откроется страница `http://127.0.0.1:8090`.
2. Вставить Vast API key (console.vast.ai → Keys). Хранится только на этом ПК: `%APPDATA%\vast-llm\config.json`.
3. **Up** → 5–10 минут → статус «Работает». В клиенте (ZCode и т.п.): провайдер OpenAI-compatible, URL `http://127.0.0.1:8080/v1`, модель `qwen3.8-27b-uncensored`, ключ любой.
4. **Down** — машина удаляется. Автоматически: после `idle_minutes` без запросов (по умолчанию 30) и после `max_hours` (12).

## Как устроено

- `app/` — утилита на Go: Vast API (поиск, аренда, удаление), встроенный SSH-туннель `127.0.0.1:8080 → машина:127.0.0.1:8080`,
  автозамена плохих хостов, переподключение, автоотключение. Наружу на машине открыт только SSH (вход по ключу утилиты).
- `image/` — Docker-образ `ghcr.io/kirilltsuran/vast-llm`: TabbyAPI (база 816c321 + production-правки), ExLlamaV3 1.5.3,
  стадия сэмплера `SS_LoopBreak` против зацикливания (`TABBY_LOOPBREAK=0` выключает). Веса не в образе: `start.sh` скачивает
  закреплённые ревизии Hugging Face с проверкой SHA256. Сторож в контейнере удаляет машину, если утилита пропала дольше `watchdog_minutes`.
- Сборка: `image.yml` публикует образ при изменениях в `image/`, `release.yml` собирает `vast-llm.exe` по тегу `v*`.

Лицензия кода TabbyAPI — AGPL-3.0 (исходники в `image/tabby-source.tgz` и `image/overlay`).
